🛠️ Entorno Integrado de Desarrollo (IDE)
Un IDE es un programa diseñado para facilitar la creación de software, proporcionando herramientas que agilizan la escritura, prueba y depuración del código.

🔹 Ejemplos de IDEs utilizados en programación:
💻 Visual Studio Code
💻 IntelliJ IDEA
💻 NetBeans
✅ La elección del IDE dependerá del lenguaje de programación y de los requisitos específicos del proyecto.

📚 Beneficios de usar un IDE:
✔️ Mejora la eficiencia al reducir tiempos de desarrollo
✔️ Proporciona un entorno organizado para la codificación
✔️ Facilita la integración con sistemas de control de versiones
✔️ Permite personalizar el flujo de trabajo según las necesidades del equipo

🚀 IDEs sugeridos para el desarrollo móvil:
Backend: Visual Studio Code
Frontend: Visual Studio Code / Android Studio

⚡ Metodología Ágil en el Desarrollo
Es un método basado en la flexibilidad y la entrega progresiva de software funcional, fomentando la colaboración y la mejora continua.

🔹 Principales enfoques de Metodología Ágil:
🔸 Scrum
🔸 Extreme Programming (XP)
🔸 Kanban
🔸 Lean Development
🔸 Feature-Driven Development (FDD)

🏆 SCRUM
Scrum es un marco de trabajo ágil que permite gestionar proyectos de manera eficiente, dividiendo el desarrollo en ciclos cortos llamados sprints para una entrega constante de valor.

📌 Roles dentro de Scrum:
👤 Scrum Master (facilita el trabajo del equipo)
👤 Product Owner (define la visión y prioridades del producto)
👥 Equipo de Desarrollo (se encarga de implementar las funcionalidades)

📊 Ventajas y Retos de Scrum
✔️ Organiza el trabajo en iteraciones con objetivos definidos
✔️ Permite descomponer el desarrollo en fases específicas:

Diseño de estructura del sistema
Implementación de funciones
Pruebas y despliegue
Evaluación y mejora

📝 Actividad Práctica en Clase
📌 ID de la Tarea: 01-HU
🔹 Ejemplo: Evaluación del proceso de compra en un sistema de carrito de compras.

🎁 Descripción
Es importante analizar el comportamiento del usuario y los requerimientos del negocio para diseñar un sistema de carrito de compras eficiente y fácil de usar.

✅ Criterios de Aceptación
☑️ Realizar entrevistas con el equipo de ventas
☑️ Documentar el flujo actual de compras
☑️ Identificar las funciones clave del carrito (añadir, modificar, eliminar productos, calcular total, etc.)
☑️ Definir los roles principales dentro del sistema (cliente, administrador, vendedor, soporte técnico)

🎯 Definición de Listo ("Definition of Ready")
✔️ Se identificaron los stakeholders clave
✔️ Se programó una reunión para discutir el proceso de ventas
✔️ Se analizaron sistemas similares en el mercado
✔️ Los roles y responsabilidades fueron revisados con el equipo
✔️ Se asignó un responsable para recopilar información
✔️ Se definió un formato estándar para la documentación
✔️ Todo el equipo tiene una comprensión clara de la historia de usuario

✅ Definición de Hecho ("Definition of Done")
✔️ Se realizaron entrevistas con clientes o usuarios clave
✔️ Se llevó a cabo un análisis comparativo de tres plataformas similares
✔️ Se establecieron al menos cuatro roles en el sistema
✔️ Se documentaron y aprobaron los requisitos del proyecto
✔️ Se generó un informe de análisis competitivo
✔️ Se definieron permisos y restricciones según los roles
✔️ Se compartió toda la documentación con el equipo de desarrollo

🚀 ¡Con este enfoque ágil estamos listos para construir una aplicación exitosa!
